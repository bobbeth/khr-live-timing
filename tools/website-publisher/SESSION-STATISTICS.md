# Preserving future session evidence

The original Bridge saves linked race telemetry only after session.isFinished; its native historical view includes Race sessions only. Recovery or a two-minute publisher alone cannot preserve a short pre-green grid or the last practice/qualifying frame that was never written.

A separately staged signed Bridge candidate adds three private capture helper functions and one optional call before that existing finished-only guard. All 168 other existing functions are unchanged. The original canonical writer, EOL logic, scoring, live output and publication logic remain intact.

The helper preserves private immutable per-session frames under Unified/session-evidence/<subsession ID>, including SDK identities/timing, complete available grids, existing pre-green/EOL observations and native SessionInfo. It flushes the last observed prior-session frame on transition and captures practice and qualifying without requiring a race finish. Hash-addressed files are never overwritten; index references are verified by the exporter. Terminal/grid capture is frequent around boundaries and throttled once settled. File failures are isolated from live Bridge reporting.

Saved observations are private evidence, never race starts. A separate completed native classification is required before supplementing results. Independently supplied native practice/qualifying tables require exact league/event identity, valid native customer IDs/car indices, completed results, session transition and source hashes. Replay, AI, fixture and spectator safeguards remain in place. Missing or unproven values stay unknown.

The website can display newly available verified non-race tables without replacing existing meeting classifications or creating duplicate sessions. Source admission and duplicate protection are regression-tested.
